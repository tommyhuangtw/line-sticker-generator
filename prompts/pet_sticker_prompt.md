# 寵物版 LINE 貼圖 Prompt（貼去 ChatGPT 使用）

## 使用方式
1. 開啟 ChatGPT（需有 GPT-4o 圖片生成功能）
2. 上傳 1-3 張你寵物的照片
3. 複製下方 prompt 貼上送出

---

## Prompt（複製這段）

```
用上傳的照片中的寵物形象作為主體，製作 LINE 貼圖。
以寵物的視角來寫文字，像是寵物在對主人說話。

請生成一張 4x3 的網格大圖（共 12 張貼圖排列在一起），灰色背景。

【文字內容】（12 張，每張一句）
1. 奴才陪我～
2. 肚子餓了喵
3. 早安～起床
4. 你快回來
5. 吃飽沒？
6. 記得餵我
7. 想睡了zzz
8. 摸摸我嘛
9. 人呢？？
10. 我最可愛吧
11. 不要出門！
12. 晚安喵～

（你可以根據寵物的品種和特性微調用語，但意思不變）

【繪製規則】
・主體要寫實感，參考照片中寵物的毛色、花紋、五官特徵
・每張貼圖中寵物要有不同的姿勢和表情（伸懶腰、歪頭、趴著、舔嘴等）
・使用像白色筆畫上去的粗手繪線條作為描邊
・線條要有隨手一筆畫出的感覺，略微粗細不均、自然隨性
・可搭配箭頭、虛線，讓畫面有視線引導感

【文字規則】
・使用手寫感粗體的中文文字，白色
・語氣偏撒嬌、傲嬌，像寵物在跟主人任性說話
・簡短的句子，不需要註解

【裝飾元素】
・可適度加入肉球、魚骨頭、小愛心、小星星、zzz 等手繪裝飾
・裝飾也使用白色手繪風格
・不要加太多，讓貼圖看起來輕鬆舒服

【格式要求】
・輸出為一張大圖，4 列 x 3 行排列
・每張貼圖之間要有明顯間隔
・灰色背景（#808080 左右）
・每張貼圖中的寵物要有白色描邊效果（像貼紙剪下來的感覺）
```
