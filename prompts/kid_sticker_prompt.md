# 小孩/寶寶版 LINE 貼圖 Prompt（貼去 ChatGPT 使用）

## 使用方式
1. 開啟 ChatGPT（需有 GPT-4o 圖片生成功能）
2. 上傳 1-3 張小孩的照片
3. 複製下方 prompt 貼上送出

---

## Prompt（複製這段）

```
用上傳的照片中的小孩形象作為主體，製作 LINE 貼圖。
文字風格用童言童語，像小朋友在說話的語氣。

請生成一張 4x3 的網格大圖（共 12 張貼圖排列在一起），灰色背景。

【文字內容】（12 張，每張一句）
1. 馬麻抱抱～
2. 我要吃飯飯
3. 早安～
4. 你快看！
5. 吃飽飽了
6. 不要上班嘛
7. 想睡覺了zzz
8. 寶寶辛苦了
9. 人呢？？
10. 我可愛吧～
11. 回我訊息！
12. 晚安安～

（可根據小孩年齡微調用語，但保持童趣感）

【繪製規則】
・主體要寫實感，參考照片中小孩的五官、髮型、膚色特徵
・每張貼圖中小孩要有不同的表情和動作（嘟嘴、歪頭、大笑、揉眼睛、比YA等）
・使用像白色筆畫上去的粗手繪線條作為描邊
・線條要有隨手一筆畫出的感覺，略微粗細不均、自然隨性
・可搭配箭頭、虛線，讓畫面有視線引導感

【文字規則】
・使用手寫感粗體的中文文字，白色
・語氣偏童言童語、撒嬌，像小朋友在說話
・簡短的句子，不需要註解

【裝飾元素】
・可適度加入小星星、小愛心、小花、泡泡、zzz 等手繪裝飾
・裝飾也使用白色手繪風格
・不要加太多，讓貼圖看起來輕鬆舒服

【格式要求】
・輸出為一張大圖，4 列 x 3 行排列
・每張貼圖之間要有明顯間隔
・灰色背景（#808080 左右）
・每張貼圖中的小孩要有白色描邊效果（像貼紙剪下來的感覺）
```

## 學齡前 vs 嬰兒用語參考

### 嬰兒版（0-2歲）
用語更簡單：抱抱、ㄋㄟㄋㄟ、要要、掰掰、嗯嗯、好棒

### 學齡前版（3-6歲）
可以更有個性：我不要！、為什麼～、我自己來、你看我畫的、我長大了
